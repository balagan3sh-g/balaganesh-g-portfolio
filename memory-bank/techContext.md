# Technical Context

## Technologies
- **Static Site Generator**: Zola
- **Theme**: Anemone (https://www.getzola.org/themes/anemone/)
- **Markup**: Markdown for content
- **Templating**: Tera templates
- **Styling**: SASS/CSS
- **JavaScript**: Minimal JS for tab functionality and animations
- **Deployment**: GitHub Pages, Netlify, or Vercel
- **Version Control**: Git/GitHub

## Development Approach
- Mobile-first, responsive design
- Progressive enhancement
- Semantic HTML for accessibility
- Optimized assets for performance
- Custom tab implementation for personal interests section

## Technical Constraints
- Static site limitations (no server-side processing)
- Content must be pre-compiled
- Anemone theme customization requirements

## Dependencies
- Zola static site generator
- Anemone theme
- Minimal JavaScript for tab functionality
- Custom CSS for green color scheme and branding

## Performance Considerations
- Optimized images (especially for project showcases and personal interest galleries)
- Minimal JavaScript usage
- Efficient CSS with no unused styles
- Fast loading times prioritized
- Lazy loading for tab content
