# System Patterns

## Architecture
- Static site generated with Zola using the Anemone theme
- Content managed through Markdown files
- Templating with Tera (Zola's template engine)
- Styling with SASS/CSS
- Minimal JavaScript for enhanced interactions (tabs, animations)

## Component Structure
- Header with navigation and green "BG" logo
- Hero section with brief introduction
- Professional section:
  - Skills component with visual representation
  - Projects showcase with descriptions and technologies used
  - Technical blog/case studies section
- Personal section:
  - Tabbed interface with four tabs (Puzzles, Biking, Trekking, Music)
  - Content area that changes based on selected tab
  - Consistent layout across different interest tabs
- Contact form or information
- Footer with social links

## Design Patterns
- Responsive design using flexbox/grid
- Component-based architecture
- Progressive enhancement for core functionality
- Green color palette based on the logo
- Consistent spacing and typography system
- Tab-based content organization for personal interests
